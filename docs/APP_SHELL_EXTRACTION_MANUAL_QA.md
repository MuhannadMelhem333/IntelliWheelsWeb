# App Shell Manual QA

This checklist is incorporated into [FRONTEND_PHASE_1_MANUAL_QA.md](FRONTEND_PHASE_1_MANUAL_QA.md). Verify that the public header renders once, desktop/mobile navigation use real routes, language switches document direction, theme/currency/service-mode selections persist, unread messages appear for verified users, auth/admin links follow verified identity, and no duplicate or legacy SPA controls appear.
